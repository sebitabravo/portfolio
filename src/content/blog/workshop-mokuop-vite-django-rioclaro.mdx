Sistema completo de monitoreo hidrológico para el Río Claro en Pucón, desarrollado como proyecto educacional en INACAP. Frontend Vite + React con shadcn/ui, backend Django REST Framework con JWT.

## Qué hace

Monitoreo de 8 sensores distribuidos a lo largo del Río Claro — desde el nacimiento en el Volcán Villarrica hasta la desembocadura en el Lago Villarrica. Dashboard con métricas en tiempo real, mapa de ubicaciones, sistema de alertas críticas y advertencias, y exportación de datos.

## Funcionalidades

- **8 sensores** simulados con niveles, temperatura y caudal
- **Dashboard** con resumen de métricas en vivo
- **Sistema de alertas** con niveles crítico, alerta y normal
- **Mapa geográfico** con ubicación de sensores
- **Exportación** de datos históricos
- **Gestión de usuarios** con roles y permisos
- **Autenticación JWT** con refresh tokens

## Stack

| Capa | Tecnología |
|------|------------|
| Frontend | Vite + React + TypeScript |
| Estilos | Tailwind CSS + shadcn/ui |
| Backend | Django 4.2 + DRF |
| Base de datos | SQLite (dev) |
| Auth | JWT |
| Monorepo | npm scripts |

## Lo que aprendí

Un monorepo Vite + Django con scripts npm unificados simplifica el desarrollo full-stack. shadcn/ui sobre Tailwind permite interfaces profesionales sin dependencia de librerías de componentes pesadas. Los dashboards de monitoreo necesitan jerarquía visual clara — las alertas críticas deben ser imposibles de ignorar.
