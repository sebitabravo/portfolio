Página web desarrollada como evaluación del curso de Programación Frontend en INACAP. Construida exclusivamente con Bootstrap, HTML y CSS, sin JavaScript.

## Qué hace

Landing page institucional que demuestra dominio de componentes Bootstrap: carrusel de imágenes, formulario de contacto con validación visual, menú de navegación responsive y tarjetas de contenido. El requisito explícito de la evaluación era no usar JavaScript — toda la interactividad se logró con componentes Bootstrap puros.

## Stack

| Capa | Tecnología |
|------|------------|
| Framework CSS | Bootstrap |
| Estructura | HTML5 |
| Estilos | CSS3 |
| Restricción | Sin JavaScript |
| Deploy | VPS con IP pública |

## Lo que aprendí

Bootstrap sin JavaScript limita pero no inmoviliza — carrusel, collapse y modals se degradan gracefulmente. La restricción de "sin JS" obliga a entender qué comportamientos son nativos del navegador y cuáles requieren scripting. Un formulario accesible necesita labels, fieldsets y leyendas — atributos HTML que Bootstrap no fuerza pero son esenciales.
