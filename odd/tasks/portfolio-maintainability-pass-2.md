## Acceptance criteria
- Invariants shared by project translations have one source of truth; translated copy and route slugs remain explicit.
- Every project blog link resolves to a generated route under the selected locale (including intentional English fallback posts).
- Navigation fragment IDs, corresponding section IDs, and contact fragment destinations cannot drift independently; current route behavior stays correct.
- Motion setup/teardown releases resources, settles state truthfully, handles repeated Astro navigation, and keeps static content usable if enhancement code never starts. On teardown, mark the motion root idle and clear the canvas only when it is still pending; preserve terminal canvas states such as ready, reduced, fallback, or disposed. Module ownership cancels the stale Hero timer; if the module never starts, its independent fallback still settles. A dynamic import resolving after the 4-second module timeout cannot reinitialize the enhancement. Queued WebGL observer/media/RAF callbacks cannot resize, restart, or schedule rendering after disposal.
- Tests describe the behavior they actually verify; no assertions are weakened merely to make the suite pass. Inline-script changes remain covered by the configured CSP hash and `pnpm verify:csp`.
- Changes remain focused per task; no broad rewrite of `Layout.astro` or `hero-webgl.ts` without a concrete need.
