Página web para el juego Masterdots desarrollada como primer proyecto de frontend en INACAP. Construida exclusivamente con HTML y CSS, sin frameworks ni JavaScript.

## Qué hace

Landing page simple para un concepto de juego llamado "Masterdots". Estructura HTML semántica con estilos CSS — el foco del proyecto estaba en entender la separación entre estructura y presentación.

## Stack

| Capa | Tecnología |
|------|------------|
| Estructura | HTML5 |
| Estilos | CSS3 |
| Enfoque | Sin frameworks, sin JavaScript |

## Lo que aprendí

Todo desarrollador frontend empieza con HTML y CSS puro. Entender el box model, la especificidad de selectores y el flujo normal del documento es fundamento que ningún framework reemplaza. La simplicidad de este proyecto refleja el punto de partida del aprendizaje.
