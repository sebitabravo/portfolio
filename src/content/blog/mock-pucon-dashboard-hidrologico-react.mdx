Dashboard de monitoreo hidrológico en tiempo real para el Río Claro en Pucón, Chile. Desarrollado como proyecto educacional en INACAP, este frontend simula la visualización de datos de sensores IoT con una interfaz profesional.

## Qué hace

Monitoreo de 4 variables hidrológicas — flujo (m³/s), nivel (m), caudal (L/s) y velocidad (m/s) — cada una con su tipo de visualización especializada: gráfico de área para flujo continuo, barras para mediciones discretas, líneas para precisión y área suave para movimiento.

## Funcionalidades

- **Panel lateral colapsable** con navegación por métricas y tooltips
- **Tarjetas de métricas** con sparklines de tendencia
- **Rangos temporales**: 30m, 1h, 6h, 24h
- **Modo pantalla completa** para análisis detallado
- **Tema claro/oscuro/automático**
- **Animaciones fluidas** con Framer Motion

## Stack

| Capa | Tecnología |

| Animaciones | Framer Motion |

## Lo que aprendí

Un dashboard de monitoreo tiene requerimientos de UX distintos a una app CRUD — la densidad de información, la jerarquía visual y la velocidad de actualización importan más que la estética. Tailwind CSS con Framer Motion permite transiciones suaves sin librerías de componentes pesadas.
