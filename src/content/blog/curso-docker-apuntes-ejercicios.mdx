Apuntes y ejercicios prácticos del curso de Docker en INACAP. Cubre desde `docker run hello-world` hasta Multi-Stage builds con aplicaciones reales en 7 stacks diferentes.

## Qué cubre

Comandos esenciales de Docker: imágenes, contenedores, redes, volúmenes y Dockerfiles. Cada concepto se aplica en un proyecto práctico:

- **01 App Node**: primer Dockerfile con Node.js
- **02 App Express**: manejo de dependencias con `node_modules`
- **03 App Flask**: prácticas con pip y pipenv
- **04 App Laravel**: entorno PHP + Composer
- **05 App Rails**: ejercicio para estudiantes
- **06 App Gin**: Multi-Stage builds con Go
- **07 App Flask + MySQL**: Multi-Stage con más de 2 stages
- **08 App Axum**: ejercicio con Rust

## Stack

| Capa | Tecnología |
|------|------------|
| Container | Docker |
| Lenguajes | Node, Python, PHP, Ruby, Go, Rust |
| Frameworks | Express, Flask, Laravel, Rails, Gin, Axum |
| Imágenes base | Alpine, Debian, Ubuntu, Fedora, Arch |

## Lo que aprendí

Docker se entiende mejor construyendo Dockerfiles para stacks reales que leyendo documentación. Cada lenguaje tiene sus idiosincrasias de contenedorización — Python necesita virtualenv, Node necesita `.dockerignore` para `node_modules`, Go se beneficia de Multi-Stage builds para imágenes mínimas.
