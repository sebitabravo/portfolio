Evaluación sumativa del módulo de minería de datos en INACAP. El proyecto consiste en un análisis exploratorio de datos del Sistema de Información de Educación Superior (SIES) de Chile usando R y el ecosistema tidyverse.

## Qué hace

Scripts de R que procesan datos de titulados por carrera, institución, región y año. El análisis incluye limpieza de datos (valores nulos, normalización de texto, conversión de tipos), transformación con `dplyr` (filter, mutate, group_by, summarise, arrange) y visualización de tendencias con `ggplot2`.

## Stack

| Herramienta | Uso |
|-------------|-----|
| R | Lenguaje principal |
| dplyr | Manipulación de datos |
| tidyr | Limpieza y normalización |
| ggplot2 | Visualización |

## Operaciones clave

- **Pipe (`%>%`)**: encadenar operaciones de transformación
- **filter + select**: filtrar filas por condiciones y seleccionar columnas relevantes
- **group_by + summarise**: agregar datos por año, región o carrera
- **mutate**: crear columnas derivadas y normalizar tipos

## Lo que aprendí

R tiene una curva de aprendizaje distinta a Python — el operador pipe (`%>%`) y la filosofía de "data frame primero" cambian cómo pensás las transformaciones. Tidyverse es un ecosistema coherente donde cada función hace una cosa y la hace bien.
