resolución — el sistema que corre

True black / pure white, never tinted. One mono family for everything, one pixel face for display, four extra pixel shapes only for the resolve animation. No accent colour, no radius, no shadows. Dark is the default; both themes are the same six tokens declared statically per theme and refined to light-dark() pairs inside one @supports block. Values recorded from source; nothing proposed.

colores — estáticos por tema, refinados con light-dark()

Six tokens declared statically: :root carries the dark values (tokens.css:67-72), [data-theme="light"] the light ones (tokens.css:91-99), and one @supports (color: light-dark(...)) block re-declares the pairs for supported engines (tokens.css:106-115) — without support the static layer is the whole story. Swatch chips show --bg, --fg, --fg-muted, --fg-faint, --line, --fill in order, top to bottom.
