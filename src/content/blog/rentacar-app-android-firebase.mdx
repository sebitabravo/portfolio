Aplicación Android nativa en Java para registro de devoluciones de vehículos arrendados. Desarrollada como proyecto educacional en INACAP.

## Qué hace

Formulario de registro con campos de fecha, patente, comentarios y estado (dropdown). Los datos se persisten en Firestore con un modelo de datos `Entrada` que incluye patente, comentario, estado y fecha. Listado de todas las entradas registradas.

## Stack

| Capa | Tecnología |
|------|------------|
| Plataforma | Android (Java) |
| Base de datos | Firebase Firestore |
| UI | XML Layouts + Spinner |
| Modelo | POJO con Firebase annotations |
| Build | Gradle |

## Lo que aprendí

Firestore con `CollectionReference.add()` es la forma más directa de persistir datos en Android sin escribir una API backend. El adapter de Spinner con `ArrayAdapter.createFromResource` resuelve dropdowns con datos estáticos en una línea. Separar el modelo de datos en su propio paquete (`modelo.Entrada`) es una buena práctica incluso en proyectos chicos.
