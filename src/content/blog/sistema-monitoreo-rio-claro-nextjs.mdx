Como complemento al sistema técnico de monitoreo del Río Claro, esta landing page institucional presenta el proyecto al público general: el problema de las crecidas del río, la solución tecnológica implementada y cómo la comunidad puede contribuir. Desarrollada como proyecto educacional en INACAP.

## Stack

| Capa | Tecnología |
|------|------------|
| Framework | Next.js 14 |
| UI | shadcn/ui + Tailwind CSS |
| Lenguaje | TypeScript |
| Estilos | CSS Modules + Tailwind |
| Deploy | Vercel |

## Qué hace

La landing page explica el problema de las crecidas del Río Claro en Pucón, el sistema de monitoreo con sensores Arduino/ESP8266 y las alertas tempranas. Componentes accesibles con shadcn/ui, diseño responsive y optimizado para SEO con Next.js.

## Lo que aprendí

Una landing page institucional es tan importante como el sistema técnico — si la comunidad no entiende qué hace el proyecto, no lo va a usar. Next.js 14 con App Router y Server Components es ideal para este tipo de contenido estático con SEO.

shadcn/ui te da componentes accesibles sin dependencia externa — el código es tuyo, lo modificás como quieras.
